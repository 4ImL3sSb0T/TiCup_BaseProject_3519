## 共用资源摘要

| 共用组 | 引脚 | 涉及外设 |
|--------|------|----------|
| 电磁 / CCD 模拟量 | **A25, A24, B25, B24** | CCD ADC1–4 与电磁运放 1–4 **一一对应共用** |
| 编码器 + 姿态 SPI | **B23 SCK, B22 MOSI, B21 MISO** | 编码器总线与姿态传感器 **共用 SPI 数据线**；各器件独立 CS |
| 屏幕 + 无线 SPI | **A12 SCK, A9 MOSI, A13 MISO** | 屏幕与无线模块 SPI **共用**；CS/RST/INT 分立 |
| 注意 | **B7** | 既出现在「无线模块串口 RX」，也出现在有刷电机 PWM 等场景时，以**本表 + 实际跳线**为准，勿与 `hardware.md` 正交编码器 B7 混用而不查 |
| **慎用（核心板）** | **A19 A20 A5 A6 A4 A3** | 特殊功能脚，尽量不用；详见上文 |

**编码器 SPI：** 四个编码器 **共用** SCK/MOSI/MISO，仅 CS1–CS4 分立，不可写成「仅编码器1 的 SPI」。

**串口区分：**

| 名称 | 信号 | 引脚 | 说明 |
|------|------|------|------|
| **无线模块 串口** | TX / RX / RTS / CMD | B6 / B7 / B2 / B3 | WiFi/无线 UART 接口 |
| **串口**（通用） | TX / RX | B15 / B16 | 独立通用串口，与无线 UART 不是同一外设 |

### 有刷电机座分组（PWM + DIR）

主板「有刷电机」座共 **8 脚、4 组**；**每一组固定 2 根线：一根作 PWM，一根作 DIR**（DRV8701 单路）。  
丝印可能都印成 PWM，**不要当成 8 路独立 PWM**，应按组接线。

| 组 | 脚对 | 建议用法 | 本工程占用（见 `hardware.md`） |
|----|------|----------|--------------------------------|
| **M1** | **B8 / B9** | 一路电机：其一 PWM、其一 DIR | **B8** = 左电机 PWM；**B9** = 右编码器 CH2（**非电机**） |
| **M2** | **B12 / B13** | 一路电机：其一 PWM、其一 DIR | **B12** = 右电机 PWM，**B13** = 右电机 DIR（**同组成对**） |
| **M3** | **A27 / A26** | 一路电机：其一 PWM、其一 DIR | **A26/A27** = 左编码器正交 A/B（**非电机**） |
| **M4** | **B11 / B10** | 一路电机：其一 PWM、其一 DIR | **B10** = 左电机 DIR；**B11** 空闲 |

**接线约定（本工程固件）：**

| 电机 | PWM | DIR | 是否同组 |
|------|-----|-----|----------|
| 左 `motor_left` | **B8**（M1） | **B10**（M4） | 否（跨 M1/M4；因 B9 给编码器） |
| 右 `motor_right` | **B12**（M2） | **B13**（M2） | **是** |

- 若编码器不占 B9，左电机宜改回 **M1 同组**（如 B8 PWM + B9 DIR），更符合座子分组。  
- M3（A26/A27）与本工程正交左编码器冲突，**勿再当电机脚**。  
- 改线时同步 `docs/hardware.md` 与 `motor.h`。

## 与本仓库软件配置的关系

| 层面 | 文档 | 说明 |
|------|------|------|
| 主板丝印 / 可接外设 | **本文** `motherboard_3507_pinout.md` | 3507 主板能力全集 |
| 工程已启用外设与冲突策略 | `docs/hardware.md` | 当前固件实际占用 |
| 芯片差异 | `docs/MSPM0G3507_vs_MSPM0G3519.md` | 3507 vs 3519 片内资源 |

**注意：** 有刷电机座按 **4 组 PWM+DIR** 理解（上表 M1~M4）。本工程固件（`motor.h`）：**左 B8 PWM + B10 DIR，右 B12 PWM + B13 DIR**。A0/A1 仅属 ToF 座，勿当电机脚。改线时同步 `hardware.md`。

编码器在主板上为 **SPI 绝对值/多路 CS 方案**；本工程软件当前使用 **定时器正交编码器（G8/G9）** 时，接线模式不同，勿将 B23–B21 SPI 与正交 A/B 脚混为一谈。
