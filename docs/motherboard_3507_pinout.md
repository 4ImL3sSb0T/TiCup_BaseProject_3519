## 核心板慎用脚

> 官方：`Example\Coreboard_Demo\E01_gpio_demo\尽量不要使用的引脚.txt`  
> 工程副本：`project/尽量不要使用的引脚.txt`

| 引脚 | 说明 |
|------|------|
| **A19, A20, A5, A6, A4, A3** | 特殊功能脚，尽量不要使用，否则可能导致核心板异常 |
| **A14** | 核心板 LED（主板蜂鸣器也常接 A14）；IO 富余时优先保留 |

主板表里即使丝印可用，**仍须先排除上表**。

## 共用资源摘要

| 共用组 | 引脚 | 涉及外设 |
|--------|------|----------|
| 电磁 / CCD 模拟量 | **A25, A24, B25, B24** | CCD ADC1–4 与电磁运放 1–4 **一一对应共用** |
| 编码器 + 姿态 SPI | **B23 SCK, B22 MOSI, B21 MISO** | 编码器总线与姿态传感器 **共用 SPI 数据线**；各器件独立 CS |
| 屏幕 + 无线 SPI | **A12 SCK, A9 MOSI, A13 MISO** | 屏幕与无线模块 SPI **共用**；CS/RST/INT 分立 |
| **B7** | 无线串口 RX 等 | 亦可能被其它方案占用；接前对照 `hardware.md` |

**编码器 SPI：** 四个编码器 **共用** SCK/MOSI/MISO，仅 CS1–CS4 分立。

**串口区分：**

| 名称 | 信号 | 引脚 | 说明 |
|------|------|------|------|
| **无线模块 串口** | TX / RX / RTS / CMD | B6 / B7 / B2 / B3 | WiFi/无线 UART 接口 |
| **串口**（通用） | TX / RX | B15 / B16 | 独立通用串口，与无线 UART 不是同一外设 |

### 有刷电机座分组（PWM + DIR）

主板「有刷电机」座共 **8 脚、4 组**；**每一组固定 2 根线：一根作 PWM，一根作 DIR**（DRV8701 单路）。  
丝印可能都印成 PWM，**不要当成 8 路独立 PWM**，应按组接线。

| 组 | 脚对 | 建议用法 |
|----|------|----------|
| **M1** | **B8 / B9** | 一路电机：其一 PWM、其一 DIR |
| **M2** | **B12 / B13** | 一路电机：其一 PWM、其一 DIR |
| **M3** | **A27 / A26** | 一路电机：其一 PWM、其一 DIR |
| **M4** | **B11 / B10** | 一路电机：其一 PWM、其一 DIR |

本工程固件实际接了哪几组：见 **`hardware.md`**。

### 电磁运放与 CCD 对应关系

原图红线为**平行对应**（勿交叉、勿漏 B25）：

| 运放路序 | ADC 引脚 | CCD 对应 |
|----------|----------|----------|
| 第 1 路 | **A25** | ADC1 |
| 第 2 路 | **A24** | ADC2 |
| 第 3 路 | **B25** | ADC3 |
| 第 4 路 | **B24** | ADC4 |
